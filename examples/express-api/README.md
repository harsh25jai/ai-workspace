# Example: Express API

**Source:** [expressjs/express](https://github.com/expressjs/express) (representative layout)  
**Stack:** TypeScript, Express  
**Validation:** PASS (R2)

## Commands run

```bash
ctxstack init && ctxstack analyze && ctxstack generate && ctxstack export
```

## Why this helps

- Detects `express` framework and `controller-service` pattern automatically
- Maps `controllers/` and `services/` modules for AI context
- Generates Express-specific Cursor rules
